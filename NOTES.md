# Notes

I used AI tools extensively throughout the project. They significantly sped up implementation and helped with most of the refactoring. I set the direction and checked the result: I reorganized folders, helpers and responsibilities, improved error handling, and formatted the TS/SCSS files. I replaced Reactive Forms with Signal Forms to match the rest of the app; I changed tag-based CSS to class selectors, fixed fractional sizes (such as 7.2 px), and removed mobile rules. I improved FCP, LCP and Speed Index: the app shell in `index.html` shows the heading before Angular starts and prepares the API connection, while `@defer` loads the order form only when opened. With more time, I would add E2E tests (for example, with Playwright), test the target browsers, and consider NgRx SignalStore as the app grows.

# Notes

I used AI tools extensively throughout the project. They significantly sped up implementation and helped with most of the refactoring. I set the direction and checked the result: I reorganized folders, helpers and responsibilities, improved error handling, and formatted the TS/SCSS files. I replaced Reactive Forms with Signal Forms to match the rest of the app; I changed tag-based CSS to class selectors, fixed fractional sizes (such as 7.2 px), and removed mobile rules. The dashboard is now rendered on the server, then Angular hydrates the existing DOM. HTTP Transfer Cache passes the initial REST responses to the browser. The root in `index.html` is empty; the former manually written app shell is no longer used. The order form still loads through `@defer` when opened. Performance claims from the earlier CSR version need fresh measurements after the SSR migration. With more time, I would add E2E tests (for example, with Playwright), test the target browsers, and consider NgRx SignalStore as the app grows.
